:::meta description: Luccet's add-ons, in their repositories under github.com/Luccet: what an add-on is, how a note loads one, and the list, from code highlighting and diagrams to citations and a wiki with search and a glossary, each linked to its page. ::: ::site-nav # Add-ons {#top} ::toc The add-ons live in repositories under [github.com/Luccet](https://github.com/Luccet), each with a README that is its page: what it does, its options, and how to use it offline. A repository can hold add-ons that work together: the wiki's three each load on their own. ## The add-ons {#list} :::table[Add-ons]{#tbl-addons} | Add-on | What it does | Its page | |---|---|---| | code | colours code fences by language, with highlight.js, in the theme's colours (`--t-code-*`) | [Luccet/code](https://github.com/Luccet/code) | | mermaid | draws ```` ```mermaid ```` fences as diagrams, in the theme's colours; can draw a built page's diagrams ahead | [Luccet/mermaid](https://github.com/Luccet/mermaid) | | lightbox | opens a figure's image full size in a dialog | [Luccet/lightbox](https://github.com/Luccet/lightbox) | | cite | cites sources from a `:::bibliography` block (BibTeX or CSL-JSON) as `@key`, and lists them | [Luccet/cite](https://github.com/Luccet/cite) | | wiki | a folder of notes as a wiki, from what [`luccet index`](tools.html#index) writes: `notes.js`, a `::notes` list of them; `search.js`, a `::search` box over them, indexed in the browser or from `search.json`; `glossary.js`, a `::glossary` of the terms they define (`:dfn[…]`, `:::definition`) and `:term[…]` links to it | [Luccet/wiki](https://github.com/Luccet/wiki) | | katex | typesets math with KaTeX, for KaTeX's look, in place of the engine's MathML | [Luccet/katex](https://github.com/Luccet/katex) | ::: **Math needs no add-on.** The engine translates each formula's TeX to MathML itself, and the browser lays it out ([Math](math.html#top)). The katex add-on is for KaTeX's look instead. ## Loading an add-on {#loading} An add-on is a script or a stylesheet that a note loads, to add what the engine leaves out: names and their meaning, behaviour, a look. List it in `data-use` on the luccet.js tag: ```html ``` Several read better in a [`:::use` block](syntax-blocks.html#use), one or more per line, which must come first in the note, after `:::meta` at most: ```html :::use https://cdn.luccet.dev/themes/v1/nord.css https://cdn.luccet.dev/code/v1/code.js https://cdn.luccet.dev/cite/v1/cite.js ::: ``` Each add-on in [the list](#list) lives in a repository under [github.com/Luccet](https://github.com/Luccet), whose README is its page: what it does, its options, and how to use it offline. From cdn.luccet.dev, an add-on's URL is `https://cdn.luccet.dev/REPOSITORY/v1/FILE`: `…/code/v1/code.js`, or `…/wiki/v1/search.js` for one of the wiki's. `v1/` follows each one's newest 1.x release, checked every hour; a release's own folder (`v1.0.0/`) never changes. A copy next to the note works too, and is the one `luccet check` can load ([remote add-ons](addon-api.html#addon-failed)). A [theme](schema.html#themes) is a stylesheet add-on, from [Luccet/themes](https://github.com/Luccet/themes). ## Your own {#own} An add-on of your own is a stylesheet, or a short script that calls `luccet.block`, `luccet.define`, `luccet.style` and the rest. [Writing an add-on](addon-api.html#top) is the contract it can rely on, versioned as `luccet.api`: how it loads, takes options and fails, what it registers, the lifecycle, math, foreign content and the command line, with [a complete one](addon-api.html#callout-addon).
