:::meta description: Luccet's add-ons, each in its own repository under github.com/Luccet: what an add-on is, how a note loads one, and the list, from code highlighting and diagrams to citations, search and a glossary, each linked to its page. ::: ::site-nav # Add-ons {#top} ::toc The add-ons each live in their own repository under [github.com/Luccet](https://github.com/Luccet), whose README is the add-on's page: what it does, its options, and how to use it offline. ## The add-ons {#list} :::table[Add-ons]{#tbl-addons} | Add-on | What it does | Its page | |---|---|---| | code | colours code fences by language, with highlight.js, in the theme's colours (`--t-code-*`) | [Luccet/code](https://github.com/Luccet/code) | | mermaid | draws ```` ```mermaid ```` fences as diagrams, in the theme's colours; can draw a built page's diagrams ahead | [Luccet/mermaid](https://github.com/Luccet/mermaid) | | lightbox | opens a figure's image full size in a dialog | [Luccet/lightbox](https://github.com/Luccet/lightbox) | | cite | cites sources from a `:::bibliography` block (BibTeX or CSL-JSON) as `@key`, and lists them | [Luccet/cite](https://github.com/Luccet/cite) | | search | a `::search` box over a set of notes, indexed in the browser or from the index [`luccet index`](tools.html#index) writes | [Luccet/search](https://github.com/Luccet/search) | | notes | `::notes`, a list of a folder's notes from the catalogue [`luccet index`](tools.html#index) writes | [Luccet/notes](https://github.com/Luccet/notes) | | glossary | `::glossary`, the terms a folder's notes define (`:dfn[…]`, `:::definition`), and `:term[…]` links to them | [Luccet/glossary](https://github.com/Luccet/glossary) | | katex | typesets math with KaTeX, for KaTeX's look, in place of the engine's MathML | [Luccet/katex](https://github.com/Luccet/katex) | ::: **Math needs no add-on.** The engine translates each formula's TeX to MathML itself, and the browser lays it out ([Math](math.html#top)). The katex add-on is for KaTeX's look instead. ## Loading an add-on {#loading} An add-on is a script or a stylesheet that a note loads, to add what the engine leaves out: names and their meaning, behaviour, a look. List it in `data-use` on the luccet.js tag: ```html ``` Several read better in a [`:::use` block](syntax-blocks.html#use), one or more per line, which must come first in the note, after `:::meta` at most: ```html :::use https://cdn.jsdelivr.net/gh/Luccet/themes@1/nord.css https://cdn.jsdelivr.net/gh/Luccet/code@1/code.js https://cdn.jsdelivr.net/gh/Luccet/cite@1/cite.js ::: ``` Each add-on below lives in its own repository under [github.com/Luccet](https://github.com/Luccet), whose README is its page: what it does, its options, and how to use it offline. From jsDelivr, an add-on's URL is `https://cdn.jsdelivr.net/gh/Luccet/NAME@1/NAME.js`; a copy next to the note works too, and is the one `luccet check` can load ([remote add-ons](schema.html#addon-failed)). A [theme](schema.html#themes) is a stylesheet add-on, from [Luccet/themes](https://github.com/Luccet/themes). ## Your own {#own} An add-on of your own is a stylesheet, or a short script that calls `luccet.block`, `luccet.define`, `luccet.style` and the rest: [Add-ons](schema.html#addons) has how they load, take options and fail, and [Writing an add-on](schema.html#writing-an-addon) a complete one.
