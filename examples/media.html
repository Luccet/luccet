:::meta title: Field notes: the estuary lang: en-GB ::: # Field notes: the estuary :::note This example is about media. It shows images that become numbered figures because they carry an id, an image that stays an image, a video and an embedded page as one-line leaves (`::video`, `::iframe`), a web component defined by a script in the note, and a plot drawn by a script into a figure (the [plots add-on](../docs/addons.html) draws one from a fence instead). The pictures are small SVG files in `img/`; the video's clip is not included, so it shows its poster. Part of [Luccet's documentation](../index.html), whose look it wears through `../docs/docs.css`. ::: ![Osprey over the estuary, 06:40.](img/osprey.svg){#fig-osprey width=70% alt="An osprey in flight above grey water"} {.round} ![The same bird, cropped to the head.](img/osprey-crop.svg){#fig-crop width=320 alt="Close crop of an osprey's head"} Compare @fig-osprey with @fig-crop.
