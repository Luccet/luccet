:::meta title: Neovim cheat sheet lang: en ::: # Neovim cheat sheet :::note This example is a cheat sheet. It shows keys with `:kbd[…]`, highlight and strikethrough, a grid of tables three to a row (`:::row{cols=3}` with `+++` between the cells), callouts, code spans that hold pipes and backticks, and a nested task list. The page is wider than a note's default, through the `--t-width` variable in the styles at the end. Part of [Luccet's documentation](../index.html), whose look it wears through `../docs/docs.css`. ::: For Neovim 0.12, with a language server attached.
